## The numbers, briefly

| Fact | Value |
|---|---|
| Commission | **5%** — $5 per 10,000 V-Bucks spent |
| Payout minimum | **$100 per rolling 12 months** |
| If you miss it | Balance **resets to zero.** A trickle earns $0 forever |
| Code lifetime | **14 days**, then the supporter must re-enter |
| Rough rate | **~$2–5 per 1,000 engaged views** on shop-adjacent content |

So: ~$20,000 of supporter spending per $1,000 you earn. That needs real view volume — roughly
200k–500k views/month for ~$1,000/month. Worth knowing before you judge early results.

## The three things that actually matter

**1. Your handle sells for you.** `@usecodebad` delivers the pitch on every impression, comment
and search result. So your videos don't have to be ads — which is exactly why this account can
grow when most creator-code accounts can't. Mention the code out loud in ~1 of 4 videos.

**2. Separate money videos from reach videos.** Shop-adjacent content converts because it catches
people already about to spend. Memes and gameplay earn ~nothing directly but build the audience
the shop videos sell to. You need both; judge each by its own job, not by revenue.

**3. Codes expire every 14 days.** Almost nobody re-enters, because almost nobody knows. A
recurring "your code expired" post recovers revenue you already earned — cheaper than any new
viewer you'll ever win. This is the most-ignored lever in the whole program.

## One rule that keeps the money

Epic's terms prohibit spam and deceptive claims, and a revoked code earns $0 permanently. So:
**automate production and your own channels, never other people's spaces.** No mass DMs, no
comment spam, no bot accounts. Full list in [RULES.md](RULES.md).

## If you want more channels later

Only once TikTok is consistent. In order of value: YouTube Shorts (same clips, minimal extra
work — `videos.insert` is now 1 quota unit with a 100/day cap, so it can be fully automated), then
a Discord for the 14-day reminders, then a GitHub Pages site for search traffic. Don't start
these yet.
