**Target length:** 75–85s · **Record:** 3 test clips + 1 reaction · **Code:** once, ~0:58

## The question
**Is the 1-Up Token actually broken, or does everyone just think it is?**

Chosen because it's this season's most-talked-about item and "1-Up Token Fortnite" is being
searched right now. Testing format works because you promise an answer in the first 3 seconds.

---

## Shot list (record before editing)

1. You picking up a 1-Up Token — clean, close
2. **Test 1:** die with a full inventory, show what you get back
3. **Test 2:** die in the storm, see if it still works
4. **Test 3:** die late-game with a good loadout — the one people care about
5. 3–4 seconds of you reacting at the end

If a test doesn't go how you expected, **keep it.** Being wrong on camera is good content.

## Editing notes

- **Cut straight to each death.** Nobody needs the ten seconds before it.
- Put a small `TEST 1 / 2 / 3` counter on screen — makes it feel rigorous and holds retention.
- Test three gets the most room. It's the payoff and the reason the video exists.
- Don't talk over the third death. Let them see it.

## Why this one converts

You're giving a real answer to something people are arguing about. The code lands *after* you've
been useful, which is the only ordering that works.

## ⚠️ Verify before filming

Test this yourself first. If the 1-Up Token behaves differently than described above, **use what
actually happens** — the whole format depends on you being right. If it turns out it really is
broken, that's a better video, just flip the verdict.
