## Editing notes

- **Cut every reload, every rotation, every looting sequence.** Dead air kills retention.
- Keep the fails *tight* — 15s each maximum. Funny, not tedious.
- The win gets room to breathe. It's the payoff.
- Overlay badge on the whole time (`creator-code/overlay/obs_overlay.html` or the end card
  via `cc_video.py --clip`).
- End on the standing-still shot so the last frame is calm and the loop back to the hook is clean.

## Why this one converts

It doesn't sell anything for 55 seconds, so people stay. The code lands once, after you've
already given them something (the "stop pushing first" tip). That ordering — value, then ask —
is the whole trick.
