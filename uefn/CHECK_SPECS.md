# Can your PC run UEFN? (2 minutes)

UEFN needs roughly: **quad-core CPU, 16GB RAM, GTX 1660 / RX 580-class GPU, 50GB+ free SSD.**
The editor is heavier than Fortnite itself — running the game fine doesn't guarantee the editor will.

## How to check (Windows)

**RAM and CPU**
1. Press `Ctrl + Shift + Esc` (Task Manager)
2. Click the **Performance** tab
3. **CPU** — note the name and "Cores" (want 4+)
4. **Memory** — note the total (want 16GB+)

**Graphics card**
1. Press `Windows + R`, type `dxdiag`, press Enter
2. Click the **Display** tab
3. Note the **Name** under Device (e.g. "NVIDIA GeForce RTX 3060")

**Free space**
Open File Explorer → This PC → check free space on your C: drive (want 50GB+, ideally SSD)

## If you're on a Mac

Fortnite hasn't been supported on macOS since the 2020 Epic/Apple dispute, so UEFN doesn't run
natively. Options are Boot Camp (Intel Macs only), Parallels, or a cloud PC — all add cost or
hassle. Tell me which Mac and I'll give you the realistic options.
